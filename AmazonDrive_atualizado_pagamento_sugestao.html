Conexão online

Conectar passageiros e motoristas

Esta configuração usa Supabase gratuito como banco compartilhado, sem Firebase. Você precisa criar um projeto e colar aqui a URL e a chave pública (anon key) do projeto.

Configuração necessária no Supabase

No painel SQL do seu projeto, execute o SQL abaixo para criar a tabela de pedidos. Este é um protótipo de testes; as políticas abertas não são seguras para lançar ao público sem autenticação e regras adicionais.

create table if not exists public.rides (
  id text primary key,
  created_at timestamptz not null default now(),
  category text,
  category_label text,
  vehicle_type text,
  origin text,
  destination text,
  distance_km numeric,
  duration_mins numeric,
  fare numeric,
  status text not null default 'pending',
  updated_at timestamptz,
  driver_lat double precision,
  driver_lng double precision,
  driver_name text,
  passenger_name text,
  passenger_photo text
);

alter table public.rides add column if not exists id text;
alter table public.rides add column if not exists created_at timestamptz not null default now();
alter table public.rides add column if not exists category text;
alter table public.rides add column if not exists category_label text;
alter table public.rides add column if not exists vehicle_type text;
alter table public.rides add column if not exists origin text;
alter table public.rides add column if not exists destination text;
alter table public.rides add column if not exists distance_km numeric;
alter table public.rides add column if not exists duration_mins numeric;
alter table public.rides add column if not exists fare numeric;
alter table public.rides add column if not exists status text default 'pending';
alter table public.rides add column if not exists updated_at timestamptz;
alter table public.rides add column if not exists driver_lat double precision;
alter table public.rides add column if not exists driver_lng double precision;
alter table public.rides add column if not exists driver_name text;
alter table public.rides add column if not exists passenger_name text;
alter table public.rides add column if not exists passenger_photo text;
alter table public.rides add column if not exists payment_method text default 'Pix';
alter table public.rides add column if not exists price_suggestion numeric;
alter table public.rides add column if not exists price_suggestion_status text;
alter table public.rides add column if not exists price_suggestion_driver text;

alter table public.rides enable row level security;
drop policy if exists "rides_test_access" on public.rides;
create policy "rides_test_access" on public.rides
  for all to anon using (true) with check (true);

grant select, insert, update, delete on public.rides to anon, authenticated;

do $$
begin
  alter publication supabase_realtime add table public.rides;
exception
  when duplicate_object then null;
end $$;

notify pgrst, 'reload schema';
Não coloque aqui a chave secreta/service_role. Use somente a chave pública anon/publishable. Enquanto não configurar o Supabase, o app continua em modo local de demonstração.
